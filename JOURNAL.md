# October 14: Printing components
I exported the components from fusion and printed them in Elegoo PLA, The print turned out nicely but i found that the front cover plate fits a bit loosely onto the main body, i have not tested with the PCB yet. I changed the design to allow for 0.04 mm more offset to allow for a tighter press fit for no visible screws.

**Total time spent: 0.5 hours**
